# Ternura Flores · Caixa

Caixa da floricultura Ternura Flores: fechamento do dia pela foto do caderno, encomendas, contas a pagar com lembrete no Telegram e relatórios mês a mês.

- **App:** <https://nossoprojeto3d.github.io/caixa-floricultura/>
- **Demonstração** (dados de exemplo, só no seu navegador): <https://nossoprojeto3d.github.io/caixa-floricultura/?demo>
- **Ligar o servidor (planilha, Gemini e Telegram):** veja [CONFIGURAR.md](CONFIGURAR.md)

## Rodar no computador

```sh
cd app
npm install
npm run dev
```

Abre em <http://localhost:5173>. Sem `URL_SERVIDOR` em `app/src/lib/config.js`, o app roda em modo demonstração.
